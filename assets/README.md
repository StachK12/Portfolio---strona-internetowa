# Zdjęcia do strony

Wrzuć tutaj pliki JPG dokładnie o tych nazwach (wielkość liter ma znaczenie — Netlify rozróżnia `Hero.jpg` i `hero.jpg`).

| Plik | Gdzie się pokazuje | Sugerowany rozmiar |
|---|---|---|
| `hero.jpg` | Główny kadr na górze strony | 2400 px szer., < 500 KB |
| `og.jpg` | Podgląd linku (Facebook, Messenger, WhatsApp) | 1200×630 px |
| `portret.jpg` | Sekcja „O mnie” | 1200 px dłuższy bok |
| `wizjer_impreza.jpg` | Wizjer — kadr z imprezy | 1600 px szer. |
| `wizjer_rocznica.jpg` | Wizjer — kadr z rocznicy | 1600 px szer. |
| `imprezy/01.jpg` … `04.jpg` | Sekcja „Imprezy” (oś czasu) | 1600 px dłuższy bok |
| `rocznice/01.jpg` … `04.jpg` | Sekcja „Rocznice i jubileusze” | 1600 px dłuższy bok |
| `seria/01.jpg` … `10.jpg` | Seria w intro (opcjonalne, brakujące są pomijane) | 1600 px szer. |

Liczbę i podpisy zdjęć zmieniasz w `index.html` w tablicach `IMPREZY`, `ROCZNICE` i `SERIA`.
